Project 3: Navitend Game - Shermings

Overview

Shermings is a browser-based puzzle game inspired by the classic Lemmings series, built using Phaser 3. Players guide Shermings through multiple levels, strategically using abilities to navigate hazards and obstacles. The project combines engaging gameplay mechanics with an intuitive UI/UX design, delivering a polished and enjoyable experience for web players.

Key Features

  • Three challenging levels with progressively increasing difficulty
  • Dynamic player interaction with abilities such as dig, glide, block, and bomb
  • Animated character sprites and smooth transitions between scenes
  • Scoring system that tracks points, time, and the number of Shermings saved
  • Responsive design optimized for both desktop and smaller screens

Technologies Used

  • JavaScript / TypeScript for game logic
  • Phaser 3 game engine for 2D game development
  • Node.js for local development and testing
  • Git & GitHub for version control and collaboration

Project 4: Rank Forge

Overview

Rank Forge is a full-stack web application that allows users to search for games, create accounts, build Top 10 game rankings, and interact with a community through comments, ratings, and leaderboards. The platform focuses on competitive ranking, user engagement, and game discovery using external API data.

Key Features

  • User authentication system with secure login and JWT-based authorization
  • Full CRUD functionality for user rankings, comments, and ratings
  • Game search and filtering with pagination for improved browsing experience
  • Community-driven leaderboard system based on aggregated user ratings
  • Automated game data updates using scheduled CRON jobs from external API integration

Technologies Used

  • Java / Spring Boot for backend development and REST API creation
  • MySQL for relational database management
  • React for frontend development and UI rendering
  • React Router for client-side routing
  • JWT for authentication and session security
  • REST API integration for external game data ingestion
  • Git & GitHub for version control

Project 5: Learning Management System (LMS)

Overview

The Learning Management System (LMS) is a full-stack web application designed to support both students and teachers in a structured online learning environment. The platform allows instructors to create and manage courses, build modular content, and design quizzes, while students can enroll in courses, complete lessons, and track their progress. The system focuses on scalable course delivery, interactive learning, and streamlined communication between teachers and students.

Key Features

  • Role-based authentication system for students and teachers
  • Course creation and management with modular lesson structure
  • Quiz and assessment creation with automated grading support
  • Student enrollment and progress tracking per course
  • Interactive learning workflow between instructors and students
  • AI-assisted content generation and API-based data enrichment using OpenAI integration
  • Secure REST API architecture for handling course data and user actions

Technologies Used

  • Java / Spring Boot for backend development and REST API services
  • MySQL for relational database management
  • React for frontend development and UI rendering
  • React Router for client-side routing
  • JWT for authentication and secure session handling
  • OpenAI API for AI-powered content generation and automated assistance features
  • Git & GitHub for version control

My Contributions

  • Added a disabled state for the form submit button to prevent multiple submissions
  • Implemented sorting functionality for courses in the course search feature
  • Added course filtering by status on the teacher dashboard page
  • Added a “Back to Top” button for improved page navigation and user experience
  • Deployed the full application with a production setup:
    • Database hosted on Aiven
    • Backend deployed on Render
    • Frontend deployed on Vercel
